# Saucedemo Web
<p>Testing a Saucedemo website by using Selenium automation framework, focusing on Login functionality, Product listing, Add to cart, Checkout process, and Validation flow end-to-end.</p>
<h2>🛠️Tech Stack</h2>
<p>1. Java</p>
<p>2. Maven</p>
<p>3. Selenium WebDriver</p>
<p>4. TestNG</p>
<p>5. Allure Report</p>
<p>6. Jenkins (CI/CD)</p>  
<p>7. Git</p>
